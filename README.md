## About This Repository

This repository documents my coursework, technical labs, and applied projects
for ITAI 1378: Computer Vision for AI.

The course explores how artificial intelligence systems interpret visual
information through image processing, machine learning, neural networks,
object detection, segmentation, and related technologies.

My focus is on understanding not only how computer vision techniques work,
but also how they can be applied to practical problems in business,
operations, and real-world environments.

This repository serves as both an academic record and a developing
professional portfolio.

## Featured Applied Projects

### Real Estate Listing Photo Enhancement

**Status:** Coursework completed; portfolio documentation in progress.

Explored traditional image processing techniques to improve real estate
listing photographs.

Techniques included:
- Contrast enhancement using CLAHE
- Image rotation and cropping
- Sharpening
- Brightness adjustments
- Before-and-after visual comparisons

This project demonstrates how image processing techniques can improve
visual presentation while preserving realistic property details.

A project summary and supporting materials will be added to the
Projects folder.

---

### Short-Term Rental Quality Assurance — Project Concept

**Status:** Exploratory proposal

Proposed a computer vision system to assist with quality assurance
inspections of short-term rental properties.

The concept involves analyzing room photographs to identify expected
objects and flag potential issues for human review before guest arrival.

Potential applications include:
- Object detection
- Room-specific inspection checklists
- Visual quality assurance
- Exception reporting

This concept draws on my professional experience in real estate,
property management, and short-term rental operations.
